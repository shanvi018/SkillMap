# \# SkillMap — Student Skill Progression Tracker

# 

# A web app for students to track skills, set learning goals, and monitor progress 

# over time — built as a personal project to practice full-stack development.

# 

# \## Features

# \- \*\*Dashboard\*\* — at-a-glance view of skills tracked, mastery count, average 

# &#x20; proficiency, and a daily streak tracker

# \- \*\*My Skills\*\* — add, edit, and categorize skills with progress percentages, 

# &#x20; tags, and proficiency levels; search, filter, sort, and export/import your list

# \- \*\*Goals\*\* — set learning targets with deadlines

# \- \*\*Progress\*\* — visual activity history over time

# \- \*\*Profile\*\* — personal details with a category breakdown chart and PDF export

# \- \*\*Achievements\*\* — unlockable badges for consistency and milestones

# 

# \## Tech Stack

# \- \*\*Frontend:\*\* React

# \- \*\*Backend:\*\* FastAPI (Python)

# \- \*\*Database:\*\* MongoDB

# 

# \## Why I built this

# I built I because I want to track my progress of my skills want to know where I stand and want to keep track of my skills and achievements. I want to keep my self motivated through seeing my skills and keep going. 

# 

# \## Setup

# 1\. Clone the repo

# 2\. Install backend dependencies: `cd backend \&\& pip install -r requirements.txt`

# 3\. Install frontend dependencies: `cd frontend \&\& npm install`

# 4\. Add your MongoDB connection string to `backend/.env`

# 5\. Run the backend: `uvicorn main:app --reload`

# 6\. Run the frontend: `npm start`
